# Автономный новостной Telegram-канал на агентах

Система сама находит новости, отбирает важные, пишет посты, проверяет их и публикует в канал. Человек нужен только один раз — чтобы запустить.

## Как это работает

```
каждые 30 мин
   │
   ▼
1. Сборщик ── RSS-ленты + поиск Google News по ключевым словам
   │           дедупликация по URL (SQLite)
   ▼
2. Аналитик ── GigaChat оценивает важность 1–10, отсекает рекламу,
   │           слухи и повторы того, что уже было в канале
   ▼
3. Автор ──── скачивает полный текст статьи, пишет пост своими словами
   ▼
4. Редактор ─ сверяет пост с источником (фактчек), правит формат,
   │           отклоняет, если факты не подтверждаются
   ▼
5. Публикатор ─ отправляет в канал с учётом лимитов, интервалов и тихих часов
               при сбоях — сообщение вам в личку
```

## Что обеспечивает работу без человека

- **Качество**: двойной контроль — аналитик (порог важности) и редактор-фактчекер.
- **Нет повторов**: дубли по ссылке и по смыслу (аналитик видит, что уже публиковалось).
- **Нет спама**: лимит постов в день, минимальный интервал, тихие часы.
- **Устойчивость**: Docker `restart: always`, повтор при лимитах Telegram, запасной вариант без разметки.
- **Мониторинг**: ошибки приходят вам в Telegram — заглядывать в сервер не нужно.
- **Защита от инъекций**: тексты статей не воспринимаются агентами как инструкции.

## Запуск (≈10 минут)

1. Создайте бота у [@BotFather](https://t.me/BotFather) → получите токен.
2. Добавьте бота в канал **администратором** с правом публикации.
3. Получите бесплатный ключ GigaChat API на [developers.sber.ru/studio](https://developers.sber.ru/studio) (вход через Сбер ID).
4. На сервере (любой VPS, можно российский, от ~200 ₽/мес):
   ```bash
   cp .env.example .env      # впишите ключи
   nano config.yaml          # тема канала и источники
   docker compose up -d --build
   docker compose logs -f    # смотреть, что происходит
   ```

Без Docker: `pip install -r requirements.txt && python -m newsbot.main`
Разовый прогон (для cron): `python -m newsbot.main --once`

## Настройка

Всё в `config.yaml`: тема и стиль канала, источники, порог важности (`min_score`), лимиты и расписание. Поднимите `min_score` до 8, если постов слишком много, опустите до 6 — если мало.

## Стоимость

Модель — бесплатно (Freemium GigaChat: 250 млн токенов Lite на 12 месяцев; бот тратит ≈ 100 млн в год). Платите только за сервер.

Важно: Freemium по условиям Сбера — для личных некоммерческих целей. Если канал будет приносить доход, нужен платный пакет.

## Идеи для развития

- Картинки к постам (og:image из статьи → `sendPhoto`).
- Ежедневный дайджест вечером.
- Отдельные каналы под разные темы — несколько `config.yaml` и контейнеров.
- Подключить платный поиск (Tavily, Brave Search) для охвата шире RSS.
